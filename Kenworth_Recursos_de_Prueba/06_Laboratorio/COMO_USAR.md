# Laboratorio
Ejecutar desde la carpeta principal: `python 06_Laboratorio/analizador.py`.
Requiere Python 3.10 o superior; no requiere paquetes adicionales. Puede ejecutarse desde otra carpeta porque resuelve rutas desde el propio script. Las salidas se escriben dentro del paquete.

Alternativa sin Python: importar CSV en una hoja de cálculo y usar filtros de fecha, origen, destino, usuario, resultado y bytes. Las plantillas permiten documentar el mismo producto sin programar.
