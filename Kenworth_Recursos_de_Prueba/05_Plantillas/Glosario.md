# Glosario
Log: registro de un evento.
Alerta: señal que requiere revisión.
Incidente: situación confirmada tras analizar contexto.
Hardening: fortalecimiento de configuración.
MFA: autenticación con más de un factor.
DMZ: segmento separado para servicios expuestos.
Falso positivo: señal que tras revisión no corresponde al problema sospechado.
Trazabilidad: posibilidad de volver a la evidencia y decisión.
Reversión: plan para volver a un estado previo si un cambio falla.
